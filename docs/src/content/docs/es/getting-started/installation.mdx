## Requisitos

- macOS con [Homebrew](https://brew.sh)
- La CLI de tu agente de IA: [Claude Code](https://code.claude.com/docs) por defecto, o cualquier otra que [configures como agente](/es/reference/configuration/#agente-de-ia)

El instalador agrega [treehouse](#treehouse) y Rust, que compila la CLI, si faltan.

## Instalar

<Steps>

1. Clona el repositorio.

   ```bash
   git clone https://github.com/falcondpr/f0 ~/dev/f0
   ```

2. Ejecuta el instalador. Elige qué instalar:

   <Tabs>
   <TabItem label="Todo">

   ```bash
   ~/dev/f0/install.sh
   ```

   Instala tmux, treehouse, Neovim, ripgrep, fd y Ghostty, enlaza las configuraciones incluidas en `~/.config` y crea [f0.app](#f0app).

   </TabItem>
   <TabItem label="Conservar mis configuraciones">

   ```bash
   ~/dev/f0/install.sh --cli-only
   ```

   Instala tmux, treehouse y la CLI `f0`, sin f0.app. Tus configuraciones de editor, tmux y terminal no se tocan.

   </TabItem>
   </Tabs>

3. Comprueba el resultado.

   ```bash
   f0 doctor
   ```

   Marca que falta un proyecto hasta que agregues uno en el [Inicio rápido](/es/getting-started/quickstart/).

4. Abre **f0** desde Spotlight, Launchpad o `/Applications`. Su launcher agrega tu primer proyecto con `a`.

</Steps>

## Opciones del instalador

| Opción | Efecto |
|---|---|
| `--no-nvim` | Conserva tu configuración de Neovim (tampoco instala Neovim, ripgrep ni fd) |
| `--no-tmux-config` | Conserva tu configuración de tmux |
| `--no-ghostty` | Conserva tu configuración de Ghostty. f0.app igual instala Ghostty, y nunca lee esa configuración |
| `--no-app` | No crea f0.app |
| `--cli-only` | Equivale a las cuatro opciones anteriores |
| `--yes` | Reemplaza las configuraciones existentes sin preguntar |

<Aside>
Si ya existe una configuración que no es un enlace de f0, el instalador pregunta
antes de reemplazarla. La respuesta por defecto conserva la tuya. Lo que se
reemplaza se mueve antes a `<ruta>.bak.<fecha>`.
</Aside>

Puedes volver a ejecutar el instalador sin riesgo: los enlaces que ya apuntan a f0 se mantienen, y f0.app se vuelve a crear.

## f0.app

f0.app es la terminal propia de f0, así sus atajos funcionan igual uses la terminal que uses para todo lo demás. Es una copia de Ghostty llamada f0, con su propio ícono y su propia configuración, `~/.config/f0/ghostty.conf`. Cada ventana abre el [launcher](/es/reference/cli/#f0-launch): eliges un proyecto, después una tarea, y al salir de su sesión vuelve la lista de proyectos. f0.app no tiene una shell suelta: `q` cierra la ventana.

- Es independiente de Ghostty: tu Ghostty, abierto o cerrado, y su configuración no la afectan, y ella no los cambia.
- El instalador copia `/Applications/Ghostty.app`, instalándolo con Homebrew si falta, renombra la copia, le da el bundle id `com.falcondpr.f0` y la firma ad hoc.
- La copia se queda en la versión de Ghostty de la que se hizo. Vuelve a ejecutar `install.sh` después de actualizar Ghostty o f0 para recrearla.
- Las ventanas arrancan en tu shell de login, así el `PATH` tiene Homebrew y Cargo aunque abras la app desde Finder. Al abrirse, f0.app también le pide a tu shell el `PATH` que ve tu terminal, incluido lo que agrega `~/.zshrc`, y suma `~/.local/bin`, `/opt/homebrew/bin` y `/usr/local/bin` si existen.

<Aside>
`install.sh` reescribe `~/.config/f0/ghostty.conf` cada vez, y mueve uno modificado a
`ghostty.conf.bak.<fecha>`. Para cambiar el tema, la fuente o los atajos de f0.app,
edita `config/ghostty/f0.conf` en el repositorio y vuelve a ejecutar el instalador.
</Aside>

La primera vez que el launcher busca repositorios en tu Escritorio o en Documentos, macOS pregunta si f0 puede leerlos.

## Tus propias configuraciones

Con `--no-nvim` o `--no-tmux-config`, f0 arma el mismo layout, pero moverte entre paneles con `Ctrl-h/j/k/l` depende de tus configuraciones. Mira [Atajos](/es/reference/keybindings/#con-tus-propias-configuraciones).

## treehouse

Cada tarea de f0 corre en su propio worktree de treehouse, así que treehouse es obligatorio. El instalador ejecuta `brew install treehouse` salvo que ya haya un `treehouse` en tu `PATH`.

## Desinstalar

Borra `/Applications/f0.app` y `~/.config/f0/ghostty.conf`, borra los enlaces de `~/.config` (`nvim`, `tmux`, `ghostty/config`), restaura las carpetas `.bak.*` si quieres recuperar tus configuraciones anteriores y ejecuta `cargo uninstall f0`. Desinstala treehouse con `brew uninstall treehouse`, y Rust con `brew uninstall rust` si lo agregó el instalador, cuando nada más los use.
