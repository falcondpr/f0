## 系统要求

- 安装了 [Homebrew](https://brew.sh) 的 macOS
- 你的 AI 智能体的 CLI：默认是 [Claude Code](https://code.claude.com/docs)，也可以是你[设置为智能体](/zh-cn/reference/configuration/#ai-智能体)的任何其他 CLI

如果缺少 [treehouse](#treehouse) 和用于构建 CLI 的 Rust，安装脚本会自动安装它们。

## 安装

<Steps>

1. 克隆仓库。

   ```bash
   git clone https://github.com/falcondpr/f0 ~/dev/f0
   ```

2. 运行安装脚本。选择要安装的内容：

   <Tabs>
   <TabItem label="全部安装">

   ```bash
   ~/dev/f0/install.sh
   ```

   安装 tmux、treehouse、Neovim、ripgrep、fd 和 Ghostty，把内置配置链接到 `~/.config`，并构建 [f0.app](#f0app)。

   </TabItem>
   <TabItem label="保留我的配置">

   ```bash
   ~/dev/f0/install.sh --cli-only
   ```

   安装 tmux、treehouse 和 `f0` CLI，不构建 f0.app。你的编辑器、tmux 和终端配置保持不变。

   </TabItem>
   </Tabs>

3. 检查结果。

   ```bash
   f0 doctor
   ```

   在你按照[快速上手](/zh-cn/getting-started/quickstart/)添加项目之前，它会报告缺少项目。

4. 从 Spotlight、启动台或 `/Applications` 打开 **f0**。在它的启动器中按 `a` 添加第一个项目。

</Steps>

## 安装选项

| 参数 | 作用 |
|---|---|
| `--no-nvim` | 保留你自己的 Neovim 配置（也不安装 Neovim、ripgrep 和 fd） |
| `--no-tmux-config` | 保留你自己的 tmux 配置 |
| `--no-ghostty` | 保留你自己的 Ghostty 配置。f0.app 仍会安装 Ghostty，并且从不读取这个配置 |
| `--no-app` | 不构建 f0.app |
| `--cli-only` | 等同于上面四个参数 |
| `--yes` | 不询问，直接替换已有配置 |

<Aside>
如果某个配置已经存在且不是 f0 的链接，安装脚本会在替换前询问。默认答案是保留你的配置。任何被替换的内容都会先移动到 `<path>.bak.<timestamp>`。
</Aside>

安装脚本可以安全地重复运行：已经指向 f0 的链接会保留，f0.app 会重新构建。

## f0.app

f0.app 是 f0 自己的终端，所以无论你平时用什么终端，它的快捷键都一样。它是一份名为 f0 的 Ghostty 副本，有自己的图标和自己的配置 `~/.config/f0/ghostty.conf`。每个窗口都会打开[启动器](/zh-cn/reference/cli/#f0-launch)：先选项目，再选任务，离开任务的会话后会回到项目列表。f0.app 不提供独立的 shell：按 `q` 关闭窗口。

- 它独立于 Ghostty：无论你的 Ghostty 是否打开，它和它的配置都不会影响 f0.app，f0.app 也不会修改它们。
- 安装脚本复制 `/Applications/Ghostty.app`（缺少时用 Homebrew 安装），重命名副本，设置 bundle id 为 `com.falcondpr.f0`，并进行 ad hoc 签名。
- 副本停留在复制时的 Ghostty 版本。更新 Ghostty 或 f0 后，再次运行 `install.sh` 重新构建它。
- 窗口在你的登录 shell 中启动，所以即使从 Finder 打开，`PATH` 中也有 Homebrew 和 Cargo。f0.app 打开时还会向你的 shell 询问终端看到的 `PATH`（包括 `~/.zshrc` 添加的部分），并在 `~/.local/bin`、`/opt/homebrew/bin` 和 `/usr/local/bin` 存在时把它们追加进去。

<Aside>
`install.sh` 每次都会重写 `~/.config/f0/ghostty.conf`，被修改过的文件会先移动到
`ghostty.conf.bak.<timestamp>`。要修改 f0.app 的主题、字体或快捷键，请编辑仓库中的
`config/ghostty/f0.conf`，然后再次运行安装脚本。
</Aside>

启动器第一次在“桌面”或“文稿”中查找仓库时，macOS 会询问是否允许 f0 读取它们。

## 你自己的配置

使用 `--no-nvim` 或 `--no-tmux-config` 时，f0 仍然会构建相同的布局，但用 `Ctrl-h/j/k/l` 在窗格之间移动取决于你的配置。参见[快捷键](/zh-cn/reference/keybindings/#使用你自己的配置)。

## treehouse

每个 f0 任务都运行在自己的 treehouse worktree 中，所以 treehouse 是必需的。除非你的 `PATH` 中已经有 `treehouse`，否则安装脚本会运行 `brew install treehouse`。

## 卸载

删除 `/Applications/f0.app` 和 `~/.config/f0/ghostty.conf`，删除 `~/.config` 中的链接（`nvim`、`tmux`、`ghostty/config`），如果想恢复之前的配置，就还原 `.bak.*` 目录，然后运行 `cargo uninstall f0`。在没有其他程序使用时，用 `brew uninstall treehouse` 卸载 treehouse；如果 Rust 是安装脚本添加的，用 `brew uninstall rust` 卸载它。
